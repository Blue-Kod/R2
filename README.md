## Обзор проекта

R2 - это система управления роботом, созданная для Orange Pi 4 Pro, предназначена для Д/У через WebXR и сайт.

## Веб-интерфейс

Панель управления — единое рабочее пространство с перетаскиваемыми панелями:
их можно группировать во вкладки, делить и закрывать (движок Golden Layout).
Доступны раскладки **Пульт**, **Отладка**, **Файлы**, **Сбор**; текущая
сохраняется в браузере. Командная палитра — `Ctrl+K`.

Панели: Видео, Сервоприводы, IK, Терминал, Логи, Python, Система,
Калибровка, Сбор данных, Файлы. Страница `/webxr` — телеоп в шлеме
(нужен HTTPS).

## Конфигурация серво (единый источник правды)

Все «серво-факты» — каналы, их имена, оффсеты, инверсия, физические и
командные лимиты, поза покоя (`REST_POSE`) и поза включения (`START_POSE`) —
определяются **только в `robov_core/servo.py`**. Остальные модули берут их
оттуда: `arm_kinematics` (поза старта, маппинг), `data_collector`, `high_level`,
dev-скрипты. Для фронтенда `servo_config()` отдаётся через
`/api/bootstrap` (объект `servo`), и браузер не хранит собственных копий имён
и диапазонов.

### Стиль

Тёмная монохромная тема на токенах OKLCH, шрифт Geist (self-hosted).
Дизайн-система — Tailwind v4: исходник `static/css/input.css`, собранный
`static/css/r2.css` коммитится, поэтому на роботе Node не нужен. Пересборка
после изменения классов (только на машине разработки):

```bash
tools/build-css.sh
```
