## Обзор проекта

R2 - это система управления роботом, созданная для Orange Pi 4 Pro, в которой есть:

- **Стереозрение**: Восприятие глубины в реальном времени с использованием двух камер
- **Компьютерное зрение**: Детекция и сегментация 79 классов (YOLOE-11s-seg) с масками, 3D-координатами и объёмом
- **Управление сервоприводами**: 8-канальное управление сервами (до 16) через PCA9685
- **Веб-интерфейс**: Панель управления в браузере, поддерживающая все функции робота
- **AI интеграция**: Обработка голосовых команд и система ответов
- **Эмоции**: Анимированные выражения глаз на дисплее

## Архитектура

```
R2/
├── launcher.py          # Установщик и менеджер процессов (запускать с sudo)
├── main.py              # Минимальная точка входа
├── requirements.txt     # Python-зависимости
├── cam_params.json      # Параметры калибровки стереокамеры
├── templates/           # HTML шаблоны веб-интерфейса
│   ├── index.html       # Главная панель управления
│   ├── view.html        # Rerun 3D-визуализация
│   └── file_manager.html
├── models/              # ONNX-модели и классы
│   ├── yoloe-11s-seg-640.onnx   # Детектор 640 (по умолчанию)
│   ├── yoloe-11s-seg-320.onnx   # Детектор 320 (быстрый)
│   ├── yoloe-11s-seg_names.json # 79 имён классов
│   └── yolov8s.onnx             # COCO fallback
├── docs/                # Документация
└── robov_core/          # Основные модули
    ├── ai.py            # AI-интеграция (EveryLLM)
    ├── camera.py        # Стереокамера, детекция, глубина, overlay
    ├── detector.py      # YOLOE ONNX-детектор с масками
    ├── depth_providers.py  # SGBM-расчёт глубины
    ├── high_level.py    # API высокого уровня (RealObject, find, scan)
    ├── eyes_display.py  # Pygame дисплей (глаза)
    ├── servo.py         # PCA9685-контроллер сервоприводов
    ├── rerun_viewer.py  # Rerun 3D-визуализация
    ├── web.py           # Flask web-сервер
    ├── config.py        # Конфигурация
    ├── keyboard.py      # Виртуальная клавиатура
    └── emotions/        # PNG-текстуры для глаз
```
