# R2 Robot Controller

R2 — это система управления роботом на базе Orange Pi 4 Pro (Debian).

## Возможности

- **Стереокамера**: Захват и обработка видео с расчетом глубины
- **Сервоприводы**: Управление 8 каналами через PCA9685 (I2C)
- **Дисплей глаз**: Pygame-рендеринг анимированных эмоций
- **Веб-интерфейс**: Flask-сервер для управления (порт 80)
- **Терминал**: Встроенная web-консоль
- **AI-интеграция**: Заглушка для голосовых команд

## Архитектура

```
R2/
├── launcher.py          # Установщик и менеджер процессов (запускать с sudo)
├── main.py              # Точка входа
├── requirements.txt     # Python-зависимости
└── robov_core/
    ├── ai.py            # AI интерфейс (заглушка)
    ├── camera.py        # Стереокамера OpenCV
    ├── config.py        # Конфигурация
    ├── eyes_display.py  # Pygame дисплей
    ├── high_level.py    # API высокого уровня
    ├── servo.py         # Контроллер PCA9685
    ├── web.py           # Flask web-сервер
    └── emotions/        # PNG текстуры для глаз
```

## Установка (Orange Pi 4 Pro)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Blue-Kod/R2.git
cd R2

# 2. Запустить launcher (требуется sudo для установки зависимостей)
sudo python3 launcher.py

# 3. После первого запуска можно запускать без sudo:
python3 main.py
```

## Зависимости APT

Launcher автоматически устанавливает:
- python3-pip, python3-pygame
- libopencv-dev, python3-opencv
- i2c-tools, libportaudio2

## Конфигурация

### Сервоприводы (`robov_core/servo.py`)

Каналы по умолчанию:
- 0: Шея (0-180°)
- 1: Правое плечо (0-270°)
- 2: Левое плечо (0-270°)
- 3: Наклон головы (0-180°)
- 4: Поворот правого плеча (0-270°)
- 5: Поворот левого плеча (0-270°)
- 6: Правый локоть (0-270°)
- 7: Левый локоть (0-270°)

Калибровка оффсетов в `servo.py` -> `DEFAULT_OFFSETS`.

### Камера (`cam_params.json`)

Файл калибровки стереокамеры (Kl, Kr, Dl, Dr, R, T, imSize).

## Использование

### Веб-интерфейс

Открыть в браузере: `http://<ip-робота>/`

Функции:
- Управление сервоприводами (ползунки)
- Просмотр видео с камеры
- Терминал и логи
- Python-консоль
- Обновление системы

### Python API

```python
from robov_core.high_level import *

# Запуск фоновых сервисов
start_background()

# Сервоприводы
angle(0, 90)  # Канал 0, угол 90°

# Эмоции на дисплее
emote("happy")

# Получить кадр с камеры
frame = get_raw_frame(left=True)
```
