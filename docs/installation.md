# Руководство по установке

Это руководство предоставляет подробные инструкции по настройке системы.

## Предварительные требования

### Аппаратные требования
- **Orange Pi 4 Pro**
- **Стереокамера** GXIVISION LSM22100 3D стерео камера 720P 120 градусов
- **Драйвер сервоприводов PCA9685** подключенный через I2C
- **Сервоприводы** 6 на 270, 40+ кг | 4 на 180, 10+ кг
- **Дисплей** 7 дюймов, HDMI + USB, сенсорный 1024x600
- **SD-Карта** 16+ GB, класс 10+

### Программные требования
- Доступ в глобальную сеть

## Быстрая установка

**❗НЕ ОБНОВЛЯЙТЕ СИСТЕМУ (apt upgrade) НИ ПРИ КАКИХ ОБСТОЯТЕЛЬСТВАХ - ОНА ПЕРЕСТАНЕТ ЗАПУСКАТЬСЯ❗**

1. Установите образ [Debian 1.0.6 Bullseye Xfce для Orange Pi 4 Pro](https://drive.google.com/drive/folders/1AzF-uTwA328qDFPaVBaKpiP4VjZjkmbS) на SD-Карту.
2. Подключите экран и подключитесь к интернету.
3. Запустите инсталлер:
    ```bash
    wget -qO- https://raw.githubusercontent.com/Blue-Kod/R2/main/installer.sh | sudo bash
    ```
    Инсталлер автоматически:
    - Установит все apt-пакеты
    - Отключит ненужные сервисы (Bluetooth, ContainerD, инфракрасный пульт, принтер и др.)
    - Добавит Onboard (экранные клавиатуры) в автозапуск
    - Скачает репозиторий и установит Python-зависимости

4. Выполните ручные шаги (инсталлер напомнит о них):
    - **Ориентация экрана** — в настройках рабочего стола установите портретную ориентацию (Right).
    - **I2C и часовой пояс** — выполните `sudo orangepi-config`, включите все I2C и настройте timezone.
    - **Перезагрузка** — `sudo reboot`.
    - **Сенсорный ввод** — настройте поворот тачскрина (см. ниже).
    - **Запуск** — `sudo python3 /opt/R2/launcher.py`.

5. Робот готов к работе. Если всё прошло успешно, вы увидите новое окно терминала, а затем глаза робота. На экране глаз робота нажмите в нижней части экрана, и откроется меню с IP и кнопкой Выход, которая завершит процесс R2.

## Ручные шаги

### Настройка I2C и часового пояса

```bash
sudo orangepi-config
```
В открывшейся утилите:
- Перейдите в раздел **System** -> **I2C** и включите все интерфейсы I2C.
- Перейдите в раздел **System** -> **Timezone** и выберите свой часовой пояс.
- Перезагрузите робота: `sudo reboot`.

### Настройка сенсорного ввода

1. Установите необходимые пакеты и сконфигурируйте X11:
    ```bash
    sudo apt install xinput
    sudo mkdir -p /etc/X11/xorg.conf.d
    sudo cp /usr/share/X11/xorg.conf.d/40-libinput.conf /etc/X11/xorg.conf.d/
    sudo nano /etc/X11/xorg.conf.d/40-libinput.conf
    ```

2. Найдите в файле секцию `Identifier "libinput touchscreen catchall"` или аналогичную. Внутри этой секции добавьте строку с матрицей трансформации для поворота на 90°:
    ```text
    Option "CalibrationMatrix" "0 -1 1 1 0 0 0 0 1"
    ```

3. Перезапустите робота: `sudo reboot`.

## Устранение неполадок

### Камера не обнаруживается
```bash
ls -la /dev/video*
sudo usermod -a -G video $USER
lsusb
dmesg | grep -i usb
```

### Проблемы с I2C
```bash
sudo i2cdetect -y 1
sudo chmod 666 /dev/i2c-1
```

### Ошибки зависимостей Python
```bash
pip uninstall opencv-python
pip install opencv-python-headless
```
