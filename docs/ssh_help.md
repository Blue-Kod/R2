# Подключение по SSH

> Вкладка **SSH** в терминале позволяет подключиться к удалённому серверу
> через протокол Secure Shell прямо из браузера.

---

## Как подключиться

1. Нажмите кнопку **SSH** над терминалом.
2. Заполните поля:
   - **Хост** — IP-адрес или домен (например `192.168.1.100`)
   - **Порт** — порт SSH (по умолчанию `22`)
   - **Пользователь** — имя пользователя (`root`, `pi`, `ubuntu`…)
   - **Пароль** — пароль пользователя
3. Нажмите **→** (или Enter в поле пароля).
4. При успешном подключении в статусе появится адрес хоста.

## Поддерживаемые приложения

Терминал поддерживает полноэкранные TUI-приложения:

- `htop`, `top` — мониторинг процессов
- `nano`, `vim`, `micro` — редакторы
- `mc` (Midnight Commander) — файловый менеджер
- `ranger` — файловый менеджер
- `btop` — мониторинг системы

> **Важно:** Настройте `TERM=xterm-256color` в удалённой системе,
> если цвета отображаются некорректно.

---

## Локальный терминал

Вкладка **Локальный** запускает командную оболочку на самом роботе:

- **Linux (Raspberry Pi)** — `/bin/bash`
- **Windows (разработка)** — PowerShell

Локальный терминал работает без пароля и не требует настройки.

## Примеры команд SSH

```bash
# Подключиться к Raspberry Pi
# Хост: 192.168.1.50
# Пользователь: pi
# Пароль: raspberry

# После подключения:
sudo apt update && sudo apt upgrade -y
htop
nano /etc/hostname
```

## Решение проблем

### «Соединение закрыто» сразу после подключения
- Проверьте, что SSH-сервер запущен на удалённой машине:
  ```bash
  sudo systemctl status ssh
  ```
- Проверьте пароль и имя пользователя.

### Терминал завис / не отвечает
- Нажмите переключение на **Локальный** и обратно на **SSH** — соединение пересоздастся.
- Или перезагрузите веб-страницу.

### Не работают цвета
- Убедитесь, что терминал настроен на `xterm-256color`:
  ```bash
  export TERM=xterm-256color
  ```

### Ошибка «Connection refused»
- SSH-сервер не запущен или порт отличается от 22.
- Проверьте: `ssh -p <порт> <пользователь>@<хост>` из командной строки.
